Examples: 6 hours, 12 hours, 3 days. The first scheduled post runs after the first full interval.

Saving a schedule does not start it. Changes to an active schedule reset the next-post countdown. The scheduler skips stale posts rather than sending a burst after a long outage.

Connect a permitted channel

Create a webhook in a Discord channel where you're allowed to post advertisements: Edit Channel → Integrations → Webhooks → New Webhook → Copy Webhook URL.

Webhook secrets are stored in the backend's private data file, never shown again in the browser. Up to five approved channels.

The updater uses GitHub releases from the repository you choose. Installing replaces application code, not your saved schedules or Discord webhooks. Your website will briefly restart.

How to publish a website update

Put the included project files in a public GitHub repository with the included .github/workflows/release.yml workflow. Change the version in package.json, then publish a GitHub release with a matching tag, for example v3.0.1. GitHub Actions attaches the verified update ZIP. Then click Check for updates above.

The button works only on Windows when this project was started using start_windows.bat on localhost. It cannot update a hosted server directly, and GitHub account access is not included.
